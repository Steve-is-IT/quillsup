How I read the sources#

  • Read directly = I fetched the page or document and read the relevant text myself (raw HTML or PDF text, or the page's text in the built-in browser). Only these support a [VERIFIED 2026-10-05: ...] tag.
  • Early summaries returned by an automated page-summary tool were used only as pointers to find the right pages. Nothing in this folder is tagged VERIFIED on the strength of such a summary.
  • The FLDOE site blocks command-line fetches (HTTP 403 "Access Denied"), so FLDOE pages were read in the built-in browser pane. The FLDOE student guide PDF triggered a download dialog in that browser, so I did not read it from the web; the project owner later supplied the PDF file and I read it in full (source 21).
  • Statutes are the 2026 Florida Statutes as displayed on the Florida Legislature's site on 2026-10-05, with history notes through s. 4, ch. 2026-33.
