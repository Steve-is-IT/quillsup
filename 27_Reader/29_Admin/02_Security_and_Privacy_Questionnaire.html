How to read this document#

This is a vendor-risk questionnaire completed by the publisher, answered truthfully for what Hackles actually is: a set of downloadable files plus a static website, with the Reader, Lab and Slides delivered as offline web pages that run in the viewer's browser. It has no server component that holds data, no accounts and no student data.

Format. The sections and question styles follow common K-12 and higher-ed review tools, namely the Higher Education Community Vendor Assessment Toolkit (HECVAT, including the Lite version, from EDUCAUSE) and student-privacy agreement templates such as those used through the Student Data Privacy Consortium. [VERIFY the current names, versions and owners of these instruments] The wording of each question below is our own short paraphrase. This is not the official spreadsheet. Your reviewer can copy any answer into the official form.
