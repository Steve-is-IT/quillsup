# Quills Up (quillsup.org)

The public website for **Hackles**, a free K-12 cyber safety kit by Competence Collective.
Hackles up? Pause. Check. Tell.

**Status: pilot draft.** The text was drafted with AI assistance and has not yet been reviewed by a school
counselor, a child-safety expert or an attorney. Read the status section on the site before you teach from it.

- `index.html` is the front door. `k-2.html`, `3-5.html`, `6-8.html` and `9-12.html` are the age-range pages.
  `all.html` is the whole kit.
- `downloads/` holds the kit as ZIP files. Bundles over 95 MB are not stored in this repository.
- The numbered folders are the web Reader, slides, classroom Lab tools and printable cards the pages link to.
- The site has no scripts that track, no cookies, no forms and no third-party requests.

This repository is generated. Do not edit it by hand: changes are made in the kit's sources and published
with `tools/publish_site.py`.
